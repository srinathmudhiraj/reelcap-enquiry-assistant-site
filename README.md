# ReelCap Enquiry Assistant — GitHub Pages package

This folder contains only the public static homepage, privacy policy, terms,
stylesheet, robots file and custom-domain marker for `reelcap.co.uk`.

Do not add n8n exports, Supabase records, credentials, tokens, screenshots with
private data or local configuration files to this repository.

## Publish sequence

1. Create a new **public** GitHub repository for this site.
2. Upload the files in this folder to the repository root.
3. Enable Pages from the default branch and root folder.
4. Confirm the temporary `github.io` URL serves `/`, `/privacy.html` and
   `/terms.html` over HTTPS.
5. In Namecheap, add the DNS records GitHub Pages shows for the repository. Do
   not guess record values.
6. Wait for HTTPS/custom-domain verification, then add the final URLs to Google
   Branding and verify each page again.

The privacy page remains an operator-review draft until hosting, retention,
Google permission scope and all connected Google data flows are confirmed.
