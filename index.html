What is available today?

This is an operator-run prototype. UK enquiry replies are tested as drafts using fictional enquiries; there is no public sign-up or connected UK customer inbox.

Working test features include saved event history, review briefs, takeover controls, WhatsApp handover alerts and technical failure email alerts.

Why connect a Google account?

The current event prototype uses an operator-authorised Gmail connection to send technical failure alerts. An alert identifies the workflow, failed step and execution to investigate.

Google sign-in is completed in the operator’s automation workspace. This website does not ask for your Google password.
